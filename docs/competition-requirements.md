## 赛道 A：AI Infra 方向

大模型推理优化及极端部署挑战

### 1. 题目

极限算力演练：消费级显卡下的高效大模型推理与性能博弈

### 2. 题目设定与任务描述

选手需在限定算力资源（1 张 RTX 4090）下，针对指定的复杂任务集（包含长文本理解、逻辑推理、代码生成等），完成以下工作：

1. 开源大模型的选型。
2. 模型量化与裁剪。
3. 推理加速及部署。

最终目标是在有限的计算资源条件下，实现高效的大模型推理，并在模型性能、推理速度和资源占用之间取得合理平衡。

### 3. 关于量化与模型选型的说明

3.1 量化训练要求

考虑到本地 RTX 4090 算力资源的限制，比赛不要求选手从头进行量化训练（QAT，Quantization-Aware Training）。

3.2 允许采用的量化方法

选手既可以自行对全量 FP16/BF16 开源模型进行训练后量化（Post-Training Quantization，PTQ），例如：

- AWQ
- GPTQ
- SmoothQuant

也完全允许直接选用开源社区中已经量化、裁剪好的现成模型版本，例如：

- GGUF
- EXL2
- AWQ

3.3 赛道重点

本赛道的重点在于考察选手：

- 对开源社区生态资源的挖掘能力。
- 对推理框架的理解与优化能力。
- 推理引擎调优和部署工程实践能力。

涉及的推理框架包括但不限于：

- vLLM
- SGLang
- TensorRT-LLM
- llama.cpp

3.4 测试与评估要求

比赛采用完全公开的基准测试集（Benchmarking Suite），不设置隐藏盲测。

### 4. 主要考核点

4.1 开源社区认知

考察选手对主流开源模型（如 Qwen2.5、Llama 3 等）不同尺寸及特性的选择能力。

重点包括模型架构、参数规模、适用任务、推理性能和硬件适配性。

4.2 量化与加速技术

考察选手对以下技术和工具的调优能力，以及量化方案的选择能力：

- AWQ
- GPTQ
- Unsloth
- vLLM
- TensorRT-LLM

4.3 Benchmark 与工程能力

考察选手在以下方面的实践能力：

- 推理性能压测。
- 内存碎片管理。
