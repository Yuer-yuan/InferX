The highest independently supported capacity remains C7 on ucloud1. The user now sets C16 as an intermediate target and permits continued work toward C32 under the same official SLO. All three existing sessions focus on performance mechanisms; accuracy is a separate, already understood evaluation stage, with no further reference-quality work. This is a single-GPU experiment on each node. The three nodes do not jointly serve a measured request. Each is a modified 49,140 MiB RTX 4090 at the original 450 W power limit. The latency contract is TTFT P95 <= 10 s and **whole-request average** TPOT P95 <= 40 ms, calculated as `(E2E - TTFT) / 511`.
